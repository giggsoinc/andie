# Andie

> Multi-modal sharp thinker — FeynTech expert explanations + Drama expert panel debates.

## What is Andie?

Andie is a skill/system prompt for AI assistants. Two modes:

- **FeynTech** (default) — assumes a world-class domain expert and explains anything with Feynman clarity. No jargon. Whiteboard style.
- **Drama** — structured expert panel debate. Named personas argue each other to stress-test decisions.

Both modes produce: OODA diagrams · Flowcharts · Tech Architecture · Lean Six Sigma DMAIC

## Install

| Platform | File | How |
|---|---|---|
| Claude.ai | `andie.skill` | Settings → Skills → Upload |
| Claude Code | `SKILL.md` | Copy to `.claude/skills/andie/SKILL.md` |
| Perplexity / ChatGPT / Codex | `andie-perplexity-chatgpt-codex.txt` | Paste into Custom Instructions |
| Manus | `andie-manus.txt` | Paste into system prompt |

## Trigger

- **FeynTech:** say `feyntech` or `default` or just ask a technical question
- **Drama:** say `drama` or `movie`
