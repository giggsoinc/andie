## 1. The brutal math (read this first)

1. **Creator credibility** — Garry Tan is YC's CEO. The content was inseparable from the authority.

3. **Zero-friction install + visible proof** — one command, plus public metrics (10K LOC / 100 PRs a week).

You don't have Tan's megaphone. So you win on the two things you *can* control: **a sharper one-sentence job** and **a better underdog story**. Reach is borrowed; narrative is built.

## 2. Fix these BEFORE launch (non-negotiable)

- **Name collision.** "ANDIE" = a known image editor; "Andi" = an AI search engine. Cold search buries you. Mitigate: always brand as **"Andie by Giggso"**, own `andie.giggso.com`, and pin the repo description with the one-liner so the GitHub result is unmistakable. (Decide consciously — keep the name and out-SEO it, or differentiate.)
- **One-command install, top of README.** ✅ Already present — keep it line one of the fold.
- **A 20-second GIF in the README.** Show a live `War` or `5 Whys` run ending in a decision. This is the screenshot that travels. (GStack's ETHOS.md mystique = your visible playbook running.)
- **An ETHOS-style file.** GStack's unsearchable `ETHOS.md` drove curiosity. You have `andie-how-it-works.md` — rename/feature a short, opinionated **`PHILOSOPHY.md`**: "Why we don't let AI answer hard questions in one shot."

## 3. The 30-Day Ignition Sequence (~2 hrs/day)

**Week 1 — Prove it works (get to first 1K stars)**
- Day 1: **Show HN** — title: *"Andie – I built a 4-playbook reasoning skill for Claude Code (no VC, no team, just me)."* Underdog flag planted. Reply to every comment for 6 hrs.
- Day 2: r/ClaudeAI + r/LocalLLaMA — lead with the GIF, not the pitch.
- Day 3: X thread — "GStack ships your code. Here's the missing half: who reviews your *decisions*?" Tag the discourse, not the person.
- Day 4–5: Get 5 respected devs to star + quote-tweet in the same hour (warm DMs prepped in advance). Stars compound on GitHub Trending.
- Day 6–7: Post the philosophy. "Why one-shot prompting fails for hard calls."

**Week 2 — Get listed (passive installs forever)**
- Submit to the **Claude skills / plugin directory**, **MCP registry**, and `npx skills` ecosystem.
- Cross-list on awesome-claude-code / awesome-llm lists via PR.
- Write one canonical "how Andie works" post on dev.to + Medium (mirror, link back to repo).

**Week 3 — The spark**
- Day 15–17: Cut a 2-min demo — Andie running `War` mode on a real incident, ending in an owner + timeline. Tight, no fluff.
- Day 18: DM the demo to 3 dev-creators (Fireship / ThePrimeagen / Theo tier) with a 2-line pitch and the GIF. One yes = 200K–800K views.
- Day 20: **Product Hunt** launch — schedule for a Tue/Wed, rally the week-1 supporters as first upvotes.

**Week 4 — Compound**
- Day 23–30: Turn the best session transcripts into a "Andie in the wild" gallery. Every shared session = a built-in ad.
- Ship the **share-loop**: every mode already ends with a recap — add a one-line "copy this debate" card so users broadcast their own sessions.
